# Street Food Tycoon (Roblox)

เกม Tycoon ร้านอาหารข้างทางไทย เริ่มจากรถเข็นผัดไท ขยายเมนูเพื่อเพิ่มรายได้

## โครงสร้าง






## วิธีใช้
1. ติดตั้ง [Rojo](https://rojo.space) แล้วรัน `rojo serve` และเชื่อมกับ Roblox Studio
   หรือคัดลอกไฟล์ไปวางใน Studio ตามชื่อโฟลเดอร์ (`.server.lua` = Script, `.client.lua` = LocalScript, อื่น ๆ = ModuleScript)
2. เปิด API Services ใน Game Settings > Security เพื่อให้ DataStore ทำงาน
3. สร้าง Game Pass และ Developer Product ใน Creator Hub แล้วใส่ไอดีใน `Config.lua`

## การหารายได้
- Game Pass: รายได้ x2, ลูกจ้างอัตโนมัติ, ร้านที่ 2
- Dev Product: ซื้อเงินในเกม 1k / 10k / 50k
- Premium Payouts: เกมเล่นวนได้ยาว

## เวอร์ชัน 2
- เมนูอาหารข้างทางไทย 15 อย่าง (หมูปิ้ง ถึง รถเข็นทุเรียน)
- 5 ภาษา: ไทย อังกฤษ ญี่ปุ่น จีน อินโดนีเซีย (`src/ReplicatedStorage/Locale.lua`) ตรวจจากภาษาเครื่องผู้เล่น สลับได้ด้วยปุ่ม 🌐
- แปลงร้านส่วนตัวสูงสุด 8 คน แผงอาหารโผล่ตามเมนูที่ซื้อ (`src/ServerScriptService/PlotService.lua`)
- เก็บเงินได้ 2 ทาง: ปุ่มบน UI หรือเดินเหยียบแผ่นเหลืองหน้าร้าน
- Leaderboard: leaderstats ในเกม + อันดับรวมทุกเซิร์ฟเวอร์ (OrderedDataStore) + ป้ายในแมพ (`LeaderboardService.lua`)
- ล็อกอินรายวัน สตรีค 7 วัน รางวัลใน `Config.DailyRewards`

## ทดสอบบนเซิร์ฟเวอร์ (ไม่มี Studio)
```
/tmp/luau/luau-analyze src/**/*.lua   # ตรวจไวยากรณ์และ lint
rojo build -o StreetFoodTycoon.rbxlx  # สร้างไฟล์เกม
```

## ทดสอบอัตโนมัติ (GitHub Actions)
ตั้ง Secrets ใน GitHub: `ROBLOX_API_KEY`, `ROBLOX_UNIVERSE_ID`, `ROBLOX_PLACE_ID`
- ทุก push: lint + build ไฟล์เกม (ดาวน์โหลดได้จากแท็บ Actions > Artifacts)
- push ไป main หรือกด Run workflow: รัน `tests/smoke.luau` บนเกมที่ publish ผ่าน Open Cloud

## เวอร์ชัน 3: เกมทำอาหารเสิร์ฟลูกค้า
- ลูกค้า NPC เดินจากถนนมาต่อคิว (`CustomerService.lua`) สั่งเมนูพร้อมแถบความอดทน 45 วิ
- โต๊ะครัวแต่ละเมนูมีโมเดลอาหารจริง (`ReplicatedStorage/Dish.lua`) กด E เพื่อทำ
- มินิเกม 3 แบบ (`MinigameClient.client.lua`): timing / mash / flip คุณภาพมีผลกับทิป
- ถือจานในมือ เดินไปกด E ที่ลูกค้าเพื่อเสิร์ฟ ผิดเมนูเสิร์ฟไม่ได้
- ชื่อเสียงร้าน (ดาว 1-5) ลูกค้าหนีชื่อเสียงลด ชื่อเสียงสูงลูกค้ามาถี่ขึ้น
- Game Pass AutoChef เสิร์ฟให้เองทุก 10 วิ (แทนระบบเงินไหลเองแบบเก่า)

## เวอร์ชัน 4: ตลาดโต้รุ่ง
- แมพกลางคืน ไฟราวสองฝั่งถนน ตุ๊กตุ๊กวิ่งวน (`MapService.server.lua`)
- แต่ละร้านมีโต๊ะสแตนเลส 4 โต๊ะ เก้าอี้พลาสติกแดงน้ำเงิน ร่ม ไฟราวหน้าร้าน
- ลูกค้ามาเป็นกลุ่ม 1-3 คน นั่งทานที่ร้าน (ต้องมีโต๊ะว่างและสะอาด) หรือซื้อกลับ (ต่อคิวหน้าเคาน์เตอร์ ต้องกด Pack ใส่ถุงก่อนเสิร์ฟ)
- ทำเป็นชุด: หมูปิ้ง/ขนมครก 4 ที่, สะเต๊ะ/ชาไทย 3 ที่, ก๋วยเตี๋ยวเรือ/ต้มยำ 2 ที่ ต่อการทำ 1 ครั้ง
- กินเสร็จโต๊ะสกปรก ต้องกด Clean ก่อนกลุ่มใหม่จะนั่ง

## เวอร์ชัน 5
- ทำ 1 ครั้ง = 1 จาน, เก็บโต๊ะแล้วถือจานสกปรกไปล้างที่อ่าง 🧼
- จ้างพนักงานด้วยเงินในเกม (แท็บ "พนักงาน"): พ่อครัวทำอาหารวางเคาน์เตอร์ / พนักงานเสิร์ฟ / เด็กล้างจาน ค่าแรงหักทุก 5 นาที เงินไม่พอพนักงานลาออก
- ROADMAP.md แผนพัฒนา, assets/ ไอคอนและภาพปก

## เวอร์ชัน 6
- อัปเกรดโต๊ะครัวในแท็บเมนู: ⚡ ความเร็ว (ลดเวลาทำ 15%/ระดับ) และ 🍱 ถาด (ทำได้หลายจานต่อครั้ง) สูงสุดระดับ 3
- เมนูแพง 7 อย่างเป็นหลายขั้นตอน (2-3 มินิเกมต่อเนื่อง) คะแนนเฉลี่ย
- ส้มตำ กะเพรา ต้มยำ ก๋วยเตี๋ยวเรือ ลูกค้าขอระดับความเผ็ด 🌶️ 1-3 ต้องเลือกให้ตรงตอนทำเสร็จ ผิดไม่ได้ทิป
- เสียงประกอบ (`ReplicatedStorage/Sounds.lua`): ลูกค้าสั่ง ได้เงิน ไหม้ ผัด เสิร์ฟ ล้างจาน คลิก ใช้เสียงในตัว Roblox เปลี่ยนเป็นไอดีจาก Creator Store ได้ และช่อง music สำหรับเพลงตลาด
- ถาด: ถือได้ 4 จานหลายเมนูพร้อมกัน เสิร์ฟทีละคนจากถาด ป้ายเหนือโต๊ะบอกจำนวนคนและรายการที่สั่ง

## เวอร์ชัน 7
- ลูกค้าพิเศษ: 🧳 นักท่องเที่ยว (ทิป x3 รอไม่ได้), 🕵️ นักรีวิว (ทำดีชื่อเสียง +20 ไม่ดี -10), 👑 VIP (จ่าย x5)
- เหตุการณ์ทุก 3-5 นาที นาน 60 วิ: 🌧️ ฝนตก (ลูกค้าอดทนลดครึ่ง ไปกางร่ม ☂️ ที่เคาน์เตอร์), ⛽ แก๊สหมด (ทำอาหารไม่ได้จนเปลี่ยนถัง), 🔥 ช่วงเร่ง (ลูกค้ามาถี่ x3 จ่าย x1.5)
- ลูกค้า 1 คนสั่งได้ 1-2 เมนู ลูกโป่งแสดงหลายบรรทัด กด E เสิร์ฟทีละจานที่ตรงกับของในถาด

## เวอร์ชัน 8
- ความอดทนลูกค้า 90 วิ + 20 วิต่อคน/ออเดอร์ที่เพิ่ม, คิวซื้อกลับยาว 6 คนเป็นแถวเดียว
- ภารกิจรายวัน 3 ข้อ (แท็บ "ภารกิจ") รีเซ็ตทุกวัน รับรางวัลเงิน
- เลเวลร้าน 5 ระดับตามรายได้สะสม: รถเข็น → แผงลอย → ห้องแถว → ร้านดัง → ตำนานตลาด ปลดล็อกโต๊ะนั่ง 2 → 4 โต๊ะ ป้ายดาวหน้าร้าน
- ครัวเดียว: กด E ที่ครัวแล้วเลือกเมนูจากรายการ อัปเกรด ⚡/🍱 เป็นของครัว เมนูที่ปลดล็อกโชว์บนชั้นหลังครัว, HUD ไม่ทับปุ่ม Roblox บนมือถือ
- แมพกรุงเทพฯ: ตึกแถวป้ายไฟ รถไฟฟ้าลอยฟ้า เสาไฟสายไฟ ทางม้าลาย ตุ๊กตุ๊ก วินมอไซค์ รถเมล์ เจดีย์วัด
- โซนตลาดนัดกลางคืน: เต็นท์ปิรามิดหลากสี 3 แถว + สองข้าง, ผู้คน, เสาไฟสูง, ตึกสูงกรุงเทพฯ เป็นฉากหลัง, หลังคาร้านผู้เล่นเป็นเต็นท์สี

## เวอร์ชัน 9: ตกแต่งร้าน + เปิดตัว
- แท็บ "ตกแต่ง": สีเต็นท์ 6 แบบ, เก้าอี้ 3 แบบ, ป้าย 3 แบบ, ของประดับ (โคมกระดาษ ต้นไม้ พัดลม ทีวี ธงชาติ แมวกวัก) บันทึกถาวร
- ของพิเศษ 3 ชิ้น (เต็นท์ทอง ป้ายทอง แมวกวัก) ปลดล็อกด้วย Dev Product "Golden Decor Pack" (`Config.DecorPackProduct`)
- สวิตช์เปิดปิดพ่อครัวอัตโนมัติ, แมพสมจริงขึ้น, `docs/STORE_DESCRIPTION.md` คำอธิบายเกม 5 ภาษา

## เวอร์ชัน 10: เป้าหมายระยะยาว
- สาขาใหม่ (Prestige): ถึง "ตำนานตลาด" กดเปิดสาขาในแท็บ "สะสม" เริ่มร้านใหม่ในย่านใหม่ (ตลาดโต้รุ่ง → เยาวราช → ข้าวสาร → ตลาดน้ำ) ทิป +10% ถาวรต่อสาขา เก็บของตกแต่งและสมุดสะสม เมนูลับประจำย่าน 3 เมนู
- สมุดสะสม: จานทอง 18 ใบ (ทำสุดยอดติดกัน 3 ครั้งมีโอกาส 25% จานทองโชว์บนชั้น) และสูตรลับ 10 ใบจากลูกค้าพิเศษ ใบละ +1% ทิป

## เวอร์ชัน 11: เล่นกับคนอื่น
- เพื่อนช่วยร้าน: กด E ที่ป้ายชื่อร้านคนอื่นเพื่อเข้าช่วย ทำอาหาร/เสิร์ฟ/เก็บโต๊ะให้ร้านนั้นได้ เงินเข้าเจ้าของ ผู้ช่วยได้ส่วนแบ่ง 30% กดอีกครั้งเพื่อเลิก
- แข่งรายสัปดาห์: อันดับรายได้สัปดาห์นี้ (OrderedDataStore รายสัปดาห์) แสดงใต้อันดับรวม แชมป์สัปดาห์ได้มงกุฎทองบนหัว

## เวอร์ชัน 12: เทศกาลไทย
- เทศกาลตามปฏิทิน (เวลาไทย): ตรุษจีน 20 ม.ค.–15 ก.พ., สงกรานต์ 10–16 เม.ย., ลอยกระทง 8–20 พ.ย., ปีใหม่ 25 ธ.ค.–5 ม.ค.
- ช่วงเทศกาล: ทิป x1.2–1.3, เมนูจำกัดเวลาซื้อได้เฉพาะช่วงนั้น (ขนมเข่ง ข้าวแช่ ขนมชั้น ข้าวต้ม), ตกแต่งรอบร้านอัตโนมัติ (โคมสี ป้าย กระทง ถังน้ำ ฟู่ ดอกไม้ไฟ)
- แก้เส้นทางลูกค้า: เข้าจากทางเดินข้างร้าน ไม่เดินทะลุครัว

## เวอร์ชัน 13
- วงจรกลางวัน-กลางคืน 24 นาทีต่อวันเกม ไฟทุกดวงเปิดเองตอนค่ำ
- แม่น้ำเจ้าพระยาหลังโซนเต็นท์ เรือหางยาว 3 ลำวิ่งไปมา ท่าเรือ พระปรางค์วัดอรุณฝั่งตรงข้าม
- ลอยกระทง: บ่อน้ำหน้าร้าน กระทงดอกไม้ลอยวน 8 ใบ โคมลอยขึ้นฟ้า
- พนักงานเดินไปทำงานแบบเห็นชัด (เดินพร้อมจังหวะก้าว)
- ซื้อพื้นที่ขยายร้าน 2 ครั้ง (20k, 80k) ครั้งละ +2 โต๊ะ, แก้พ่อครัวหยุดทำงานเมื่อเคาน์เตอร์ตัน (ทิ้งจานที่ไม่มีออเดอร์รอ), Game Pass เปลี่ยนเป็น Premium Staff
