# Life Story — Roblox life simulation (Sims-style)
โฟลเดอร์นี้เป็นเกมที่สอง แยกจาก Street Food Tycoon (root)
- `docs/GAME_DESIGN.md` เอกสารออกแบบเต็ม
- `src/` โค้ด Rojo (`default.project.json`) · `tests/` เทสต์รันบนเซิร์ฟเวอร์ Roblox จริงผ่าน Open Cloud
- Workflow: `.github/workflows/life.yml` (secrets: ROBLOX_API_KEY, LIFE_UNIVERSE_ID, LIFE_PLACE_ID)
## เวอร์ชัน
- 0.1.0 MVP: ตัวละคร (นิสัย 20/ความฝัน 8), ความต้องการ 8, อารมณ์ 13, ช่วงชีวิต 7 + มรดกข้ามรุ่น, ทักษะ 10, อาชีพ 6 + พาร์ทไทม์ (กะงาน = มินิเกม 3 รอบ), โรงเรียน/มหาวิทยาลัย 4 คณะ, บ้าน (อพาร์ตเมนต์→บ้าน 3 ขนาด) เฟอร์นิเจอร์ 30 ชิ้น วางเองได้, บิล, ไฟไหม้, โรค 6 + ประกัน + รักษา, ความตาย 6 แบบ, ผู้คน NPC 12 + ผู้เล่น, ปฏิสัมพันธ์ 12, แต่งงาน/หย่า/ลูก/สัตว์เลี้ยง, คาเฟ่ (จ้างผู้เล่น), เหตุการณ์สุ่ม, เทศกาล 5, ฤดูกาล 4, เป้าหมายรายวัน, รางวัลรายวัน, 5 ภาษา, Game Pass 5 / Dev Product 5 (ใส่ ID ภายหลัง)
